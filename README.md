# Espace Soned Afrique — Pointage V11

Nouvelle version du pointage (le suivi viendra plus tard). La V10 reste intacte dans `p-scann-v10`.

## Installer pour tester (30 min)
1. Ouvrir le projet Apps Script du pointage. Garder une copie de l'ancien code (Fichier > Faire une copie).
2. Remplacer tout le contenu de `Code.gs` par `apps-script/Code.gs`, puis Enregistrer.
3. Déployer > Gérer les déploiements > modifier le déploiement existant > Nouvelle version > Déployer (même lien, donc pas de changement d'adresse).
   Si vous créez un nouveau déploiement, mettre la nouvelle adresse dans `script.js` (CONFIG.endpoint).
4. Publier les fichiers du dossier (GitHub Pages ou votre hébergement habituel) dans un dossier séparé pour la V11.
5. Tester avec 3 ou 4 personnes : Bureau, Télétravail, urgence, week-end, messages, Utilitaire.
6. Créer le code de confidentialité (RH > Utilitaire > Réglages > Initialisation), différent du code RH.

## Avant le lancement
- Ne pas effacer ni remplacer la V10 avant la fin des tests.
- Effacer les données de test (Initialisation), puis « Verrouiller au lancement ».
- Tester les e-mails, imprimer les QR d'entrée et les badges.
- Autorisation écrite de Soned avant toute vente de l'application.
